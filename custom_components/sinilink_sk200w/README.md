# Sinilink SK200W (Home Assistant 自定义集成)

通过 **Modbus RTU over UDP** 读取 Sinilink（XY-SK 系列）可调电源的各项数值，并在 Home Assistant 中提供
`binary_sensor`、`sensor`、可写的 `number`（设定电压 / 电流）以及一个用于开始 / 停止轮询的 `switch` 实体。

## 功能

- 通过 Modbus RTU over UDP（`pymodbus` + `FramerType.RTU`）连接指定 IP 的设备。
- 支持配置 **读取间隔**（可在集成选项里随时修改）。
- 设备创建后生成一个 **“数据更新” 开关**：打开后按间隔轮询设备，关闭后完全停止 Modbus 通信
  （保留最后一次读数）。
- 提供布尔状态 binary sensor：输出状态、恒流模式、恒压模式、保护状态、通信状态。
- 提供数值 sensor：输出电压 / 电流 / 功率、输入电压、温度、外部温度、电池容量 / 能量。
- 提供可写的 number：设定电压 / 电流、欠压 / 过压 / 过流 / 过温 / 探头过温保护、最大功率 / 时间 / 容量 / 能量。
- 提供 switch：`输出`（开关电源输出）、`上电状态`、`数据更新`（轮询启停）。

## 安装

1. 将 `sinilink_sk200w` 目录复制到 Home Assistant 配置目录下的 `custom_components/`。
2. 重启 Home Assistant。
3. 进入 **设置 → 设备与服务 → 添加集成**，搜索 `Sinilink SK200W`。
4. 填写设备 IP、端口（默认 `1024`）、Modbus 从站地址（默认 `1`）以及读取间隔（默认 `5` 秒）。

## 配置项

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| Host | 设备 IP 地址 | — |
| Port | UDP 端口 | `1024` |
| Modbus slave address | 从站地址 | `1` |
| Update interval | 读取间隔（秒） | `5` |

## 寄存器映射（Holding Registers）

| 寄存器 | 含义 | 缩放 |
| --- | --- | --- |
| `0x0000` | 设定电压 | ×0.01 V |
| `0x0001` | 设定电流 | ×0.001 A |
| `0x0002` | 输出电压 | ×0.01 V |
| `0x0003` | 输出电流 | ×0.001 A |
| `0x0004` | 输出功率 | ×0.01 W |
| `0x0005` | 输入电压 | ×0.01 V |
| `0x0006` | 电池容量（32 位，低字在前） | ×0.001 Ah |
| `0x0008` | 电池能量（32 位，低字在前） | ×0.001 Wh |
| `0x000A`–`0x000C` | 输出时长 时 / 分 / 秒 | 1 |
| `0x000D` | 内部温度（有符号） | ×0.1 °C |
| `0x000E` | 外部温度（有符号） | ×0.1 °C |
| `0x0010` | 保护状态 | 位域 |
| `0x0011` | 恒流 / 恒压 模式（bit0：1=恒流） | 位域 |
| `0x0012` | 输出使能（bit0） | 位域 |
| `0x0052` | 欠压保护 S-LVP | ×0.01 V |
| `0x0053` | 过压保护 S-OVP | ×0.01 V |
| `0x0054` | 过流保护 S-OCP | ×0.001 A |
| `0x0055` | 最大功率 S-OPP | ×0.1 W |
| `0x0056`/`0x0057` | 最大输出时间（时 / 分） | 1 |
| `0x0058`/`0x0059` | 最大容量 S-OAH（32 位，低字在前） | ×0.001 Ah |
| `0x005A`/`0x005B` | 最大能量 S-OWH（32 位，低字在前） | ×0.01 Wh |
| `0x005C` | 过温保护 S-OTP | 1（°C） |
| `0x005D` | 上电输出状态 S-INI | 0/1 |
| `0x005E` | 探头过温保护 S-ETP（SK 系列） | 1（°C） |

除 `0x0000–0x0012` 外，还会读取 `0x0052–0x005E`（M0 参数集）。该区块在部分机型上可能不存在，
读取失败时不影响整体更新（保留上次的值）。

> 电流缩放默认按 `0.001 A / 单位` 处理。若实际读数相差 10 倍，请按设备手册调整 `const.py` 中的
> `CURRENT_SCALE`。

> 当未连接温度探头时，设备会返回哨兵值（原始 `8888`，即 `888.8 °C`）。集成会把该值识别为
> “未知”，对应 sensor 显示为 unknown，CLI 显示为 `n/a (no sensor)`。哨兵值定义在 `const.py`
> 的 `TEMPERATURE_INVALID_SENTINELS`。

## 实体

- **binary_sensor**: `输出状态`、`恒流模式`、`恒压模式`、`保护状态`、`通信状态`。
  `输出状态` 的附加属性包含全部测量数值。
- **sensor**: `输出电压`、`输出电流`、`输出功率`、`输入电压`、`温度`、`外部温度`、
  `电池容量`、`电池能量`。
- **number**（可写）：`设定电压`、`设定电流`、`欠压保护`、`过压保护`、`过流保护`、`最大功率`、
  `最大输出时间`、`最大输出容量`、`最大输出能量`、`过温保护`、`探头过温`。
  范围定义在 `const.py`（`MAX_*` 常量，本机型为 40 V / 9 A / 200 W / 110 °C），换机型时请自行修改。
- **switch**：`数据更新` —— 开始 / 停止 Modbus 轮询；`输出` —— 打开 / 关闭电源输出（`0x0012`）；
  `上电状态`。

> `数据更新` 关闭时，**除该开关本身外所有实体都会变为“不可用”**（因为不再读取数据）。

> ⚠️ 常见注意事项：
> - 若把**设定电压**调得高于**过压保护**阈值，设备会立即锁存 OVP 保护（写入前集成为此会打印警告）。
> - 打开 `输出` 前集成会先清除保护锁存（写 `0x0010 = 0`），否则设备会拒绝开启输出。
> - 设备会丢弃间隔不足 ~50 ms 的请求，客户端已自动加入最小帧间隔，避免写入丢失。
> - `上电状态` 设为开会在每次上电时自动开启输出，请谨慎使用。
